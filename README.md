# 내 방식 QR — 범용 접근성 프로필 패스

QR 한 번이면 키오스크가 나에게 맞춰요. 2026 AI 라이프 솔루션 챌린지 출품작.
아이디어: 2026 AI 라이프 아이디어 챌린지 수상 후보작 「내 방식 QR — 범용 접근성 프로필 패스」

- 시험 주소: https://yoonwork.github.io/myway-qr/
- 휴대폰으로 프로필 만들기: `profile.html`
- 키오스크 체험: `kiosk.html?site=hospital` (병원 접수), `kiosk.html?site=cafe` (카페 주문)
  - `#p=MWQ1-…` 를 붙이면 그 프로필로 바로 열려요. `&test=1` 은 걸린 시간·누른 횟수를 보여 주는 시험 모드
- 시연 영상(약 4분): `assets/video/myway-demo.mp4` (첫 화면 #demo)
- 운영자 리포트·기기 점검: `report.html`
- AI 성능 시험: `eval.html` (확인용·개발용 문장)

## 구조

| 파일 | 하는 일 |
|---|---|
| `assets/mwq.js` | 프로필 형식(기능 코드만, 개인정보 없음), 폰 저장, 익명 통계 |
| `assets/ai.js` | 기기 안 AI: multilingual-e5-small(8비트)로 말 ↔ 진료과·메뉴·화면 버튼 맞추기, 엉뚱한 말 거르기, 응급 표현 감지(낱말 규칙 + AI) |
| `assets/speech.js` | 브라우저 음성 합성(안내)·음성 인식(말로 하기) |
| `assets/kiosk.js` | 키오스크 화면 엔진: 글자·대비·버튼·제한시간 바꾸기, 한 화면 버튼 3~4개로 줄이기(자주 쓰는 순), 말한 내용에 맞는 버튼을 AI가 맨 앞으로, 어느 화면에서든 말로 버튼 고르기, 응급 표현은 직원 호출, 결제·접수 전 확인, 끝나면 삭제 |
| `assets/data/*.js` | 병원·카페 문구(보통/쉬운 말), 진료과 예시 문장, 메뉴 별칭, 시험 문장 |

서버가 없는 정적 사이트예요. AI 모델은 처음 한 번 Hugging Face에서 받아 브라우저에 저장하고, AI 판단(문장 비교)은 기기 안에서만 해요. 다만 ‘말로 하기’의 음성→글자 변환은 브라우저 음성 인식이라, 크롬에서 기기 안 인식을 쓸 수 없으면 구글 서버를 거쳐요.
